# Rick's Closet | 3D Fashion Showcase

An interactive 3D clothing collection with garment browsing, product inspection, color and size controls, and a demo cart.

[Live demo](https://animation-clothes-six.vercel.app/)

## Included interfaces

- 3D garment browsing and product inspection.
- Colorway and size controls.
- Auto-tour and demo cart interface.

## Built with

JavaScript, Three.js and Vite.

## Run locally

Install a Node.js version supported by the framework dependencies in `package.json`.

```bash
npm install
npm run dev
```

Open the local URL printed by the development server.

## Production build

```bash
npm run build
```

## Demo scope

Garments are procedurally rendered and animated. This is a visual showcase and demo shopping experience, not a live shop.
